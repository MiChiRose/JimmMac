# Проверка оформления JimmMac 0.14.2 (build 23)

Проверено 3 ноября 2026 на OS X 10.9.5. Производственная сборка:
Xcode 5.1.1 / SDK 10.9, Intel x86_64, Mach-O minimum OS X 10.8.

## Проверки

- 465 проверок AppKit: прежние сценарии, все три оформления, офлайн-история,
  перенос данных и новые элементы исторических окон.
- 170 проверок протокола, хранения и входа с NSURLSession; 170 с NSURLConnection.
- 30 проверок HTTP обоих транспортов.
- 514 строк перевода RU/EN: покрытие и совпадение форматных параметров.
- Итого 835 автоматических проверок и проверка перевода, все пройдены.

Дополнительно проверены переключение реальных разговоров через вкладки,
вставка смайлика в черновик и отмена через responder chain, закрытие кнопкой
с клавиатуры, сохранность черновиков, отсутствие пересечений поля ввода и новых
кнопок, наличие видимых глифов сообщений после смены темы и размеров окна.

Снимки четырёх основных исторических окон просмотрены после отрисовки на
Mavericks. Используются вымышленные имена, контакты, сообщения и отдельные
тестовые хранилища. Пользовательская переписка не читается.

## Исправление прокрутки

После изменения ширины и повторной раскладки старое смещение могло оказаться
за концом укоротившейся страницы. Высота документа теперь пересчитывается по
layout manager, а сохранённая позиция ограничивается допустимыми границами.
Сохраняются выделение и переход к непрочитанному сообщению; прокрутка
восстанавливается в допустимых границах.

## Кнопки и окна

Исторические режимы используют наследников NSButtonCell, NSPopUpButtonCell и
NSSegmentedCell. AppKit сохраняет обработку событий, доступность, меню, фокус,
состояние нажатия и стандартную цепочку команд; меняется их отрисовка.
Системные заголовки окон остаются нативными. Текущий режим использует обычную
отрисовку AppKit. Размеры шрифта пользователя сохраняются; при смене семейства
в историческом режиме сохраняются жирное и курсивное начертания.

## Установщик и границы проверки

Оформленный DMG использует прежний HFS+ / UDZO. Проверка hdiutil выполняется
на современном Mac и Mavericks. Приложение установлено в /Applications/JimmMac.app;
совпадение исполняемого файла проверено SHA-256.

Настоящие 10.8 и 10.13 недоступны: их запуск не заявляется проверенным.
В 0.14.0 пользователь подтвердил сохранённый вход, базовые функции и переключение
тем. В 0.14.2 оформление дополнительно сверено с исходными изображениями.
