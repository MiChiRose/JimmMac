# Три оформления JimmMac

В меню **«Вид → Оформление»** можно переключиться без выхода из аккаунта.

| Режим | Вид и поведение |
| --- | --- |
| Текущий | Единое окно, серебристые панели, мягкий зелёный заголовок, крупные строки контактов. |
| Ностальгия · ICQ для Mac 2011 | Ярко-зелёная шапка, светлый отдельный список контактов, аватары, отдельное окно переписки. |
| Ностальгия · ICQ Pro 2003b | Компактный список с цветками статуса, бежевые панели, прямоугольные кнопки, отдельное окно переписки. |

В исторических режимах один щелчок выбирает строку. Двойной щелчок или Enter
открывает переписку; Escape в переписке возвращает фокус в окно контактов.
Cmd+1 / Cmd+2 переключают разделы, Cmd+L открывает поиск в списке.
Tab и Shift+Tab перемещают фокус внутри своего окна. Закрытие окна сохраняет
соединение и черновики; Cmd+0 или значок Dock возвращают окна.

Оформления воспроизводят характер и компоновку выбранных исторических образцов.
Системные заголовки, меню, выделение текста и диалоги остаются AppKit текущей ОС:
это не точная копия всех пикселей AIR или Windows. Используются имеющиеся ресурсы
цветка и статусов ICQ; источники ресурсов перечислены в README.

- [ICQ Pro 2003b — иллюстрация в истории ICQ на Trashbox](https://trashbox.ru/link/istoriya-icq).
