# Проверка JimmMac 0.14.0 (build 21)

Дата: 3 ноября 2026. Доступный MacBook: OS X 10.9.5 (13F1911).
Приложение собрано Xcode 5.1.1 / SDK 10.9, Intel x86_64, minimum OS X 10.8.
Bundle ID и расположение пользовательских данных сохранены.

## Автоматические проверки

- 170 проверок протокола, хранения, входа и обновлений с NSURLSession.
- Те же 170 проверок с совместимым путём NSURLConnection для 10.8.
- 30 проверок HTTP обоих транспортов.
- 436 проверок AppKit на Mavericks: прежние сценарии и новые офлайн-сессии,
  отключение уведомлений переписки, переключение трёх оформлений, геометрия
  минимальных окон, отдельные цепочки Tab, Escape в исторической переписке,
  запуск на английском и восстановление резервной копии.
- Проверка покрытия 505 статических строк RU/EN и совпадения printf-параметров.
- Итог: 806 автоматических проверок плюс проверка перевода, все пройдены.

Тесты используют вымышленные аккаунты, отдельные временные каталоги, подменённую
Связку ключей, уведомления и звук. Пользовательская переписка не используется.

## Перенос данных

Проверены снимок живой WAL-базы, перенос 10 002 сообщений, повторный импорт без
дубликатов, сохранение имеющихся флагов прочтения, перевод незавершённой отправки
в неопределённое состояние, отклонение другого UIN, прав доступа 0600, повреждённого
файла и некорректной строки с полным откатом импорта. Перенос сохраняет разные
черновики вместе. Настройки уведомлений и оформления применяются после восстановления.
Авторизационные данные и указатель сохранённого входа исключены из манифеста.

Резервная копия использует DELETE journal mode: SQLite в старых системах должен
открывать один файл без дополнительных WAL/SHM. Исходная рабочая база остаётся WAL.

## Сеть и установщик

Собранное приложение успешно читает публичный релиз GitHub обоими транспортами
на Mavericks; диагностический режим не открывает аккаунт и не читает его данные.
Mach-O содержит LC_VERSION_MIN_MACOSX 10.8 и SDK 10.9. Сборка проходит без предупреждений.
DMG использует HFS+ / UDZO; контрольная сумма `hdiutil verify` проходит на современном
Mac и Mavericks. Исполняемый файл установленной копии совпадает со сборкой.

## Границы проверки

Настоящие OS X 10.8 и macOS 10.13 сейчас недоступны. Сборка с minimum 10.8 и
проверка её совместимого транспорта на 10.9 не заменяют запуск на этих системах.
Остаются нужны проверки входа/TLS, получения сообщений, уведомлений, резервной
копии и трёх оформлений на 10.8 и 10.13. Заявляется целевой диапазон, а не
подтверждённое прохождение тестов на каждой его версии.

После установки пользователю предложена ручная проверка сохранённого входа,
бота 11114 и трёх оформлений на Mavericks. Её результат фиксируется отдельно.
